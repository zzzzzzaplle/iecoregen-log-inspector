# 分析日志

## 阶段

分析日志格式，确定核心功能边界。

## 样例

- 样例日志：`logs/AI-Games-Hex/deepseek-v4-flash/hexgame2/log.txt`
- 样例单位：`AI-Games-Hex/deepseek-v4-flash/hexgame2#sample2.mwe2`

## sample开始/结束

- sample 开始：`[deepseek-v4-flash] 正在启动 sample2.mwe2...`
- sample 结束：`sample2.mwe2 启动完成`
- 样例中从 <sample 开始> 到 `reactor.util.Loggers -- Using Slf4j logging framework` 之前视为无效前缀，主要是启动、依赖扫描、项目注册等噪声。

## 日志异常/错误模式
分析每个 sample 前，先扫描异常/错误模式,如果有错误模式需要额外标注这些信息的行号
目前已整理的错误模式有
举例
- Caused by: java.io.EOFException: EOF reached while reading 
报错pattern (只要日志里有报错就肯定会有这句话,但有这句话不一定说明该日志出错)
- Cannot invoke "java.lang.Iterable.iterator()" because "iterable" is null
- Caused by: xxxx
## 每个阶段的 开始/结束 标记

### EOperation 标注阶段
- 开始标记: `Annotating EOperations`
- 结束标记: `Verify Annotations`
- (note:结束标记其实是下一个阶段的开始)
### 需求校验阶段
- 开始标记: `Verify Annotations`
- 结束标记: `Verification End`
### 代码补全阶段
- 开始标记: `Generating EMF model code`
- 结束标记: `Code Fixing`

此时还要额外说明:代码补全是按照类的顺序进行的,一次补全一个类的所有操作,所以一个代码补全阶段中可以分成每一个类补全的小阶段
  - 每个类的操作补全开始标记:`Code Completion for class name1`
  - 结束标记 :`Code Completion for classname2`

每个类补全中可能包含若干工具调用，工具调用以 Executing/Successful/Converting 三类日志包围(工具调用的顺序不是固定的)
1. 列举此case的目录结构
   2. 开始标记:`Executing tool call: ListJavaFiles`
   3. 结束标记: `Successful execution of tool: ListJavaFiles` 以及 `Converting tool result to JSON.`
2. 对该代码导航,提供与之有关的其他classes的信息
   3. 开始标志:`Executing tool call: NavigateInModel`
   4. 结束标志: `Successful execution of tool: NavigateInModel`以及 `Converting tool result to JSON.`
3. 对导航的代码进行代码总结
   4. 开始标志:`Executing tool call: GetCodeSummary`
   5. 结束标志: `Successful execution of tool: GetCodeSummary`以及 `Converting tool result to JSON.`

### 代码修复阶段
- 开始标记: `Code Fixing`
- 结束标记: `There is no more compilation error`

此时还要额外说明:代码修复是按照类的顺序进行的,针对编译报错的类,一个一个按顺序进行
(如果 Code Fixing 后没有出现 Fixing classname，而是直接编译并输出 There is no more compilation error，表示没有需要逐类修复的编译错误；这是正常的
)
  - 每个类的代码修复开始标记:`Fixing classname1`
  - 结束标记 :`Fixing classname2`

每个类修复过程中可能包含若干工具调用，工具调用以 Executing/Successful/Converting 三类日志包围(工具调用的顺序不是固定的)
1. 列举此case的目录结构
    2. 开始标记:`Executing tool call: ListJavaFiles`
    3. 结束标记: `Successful execution of tool: ListJavaFiles` 以及 `Converting tool result to JSON.`
2. 对该代码导航,提供与之有关的其他classes的信息
    3. 开始标志:`Executing tool call: NavigateInModel`
    4. 结束标志: `Successful execution of tool: NavigateInModel`以及 `Converting tool result to JSON.`
3. 对导航的代码进行代码总结
    4. 开始标志:`Executing tool call: GetCodeSummary`
    5. 结束标志: `Successful execution of tool: GetCodeSummary`以及 `Converting tool result to JSON.`
