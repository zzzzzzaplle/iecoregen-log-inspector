此目录用于保存 iecoregen-log-inspector 项目的持续上下文。

使用约定：
- 后续与本项目相关的关键目标、分析结论、设计决策、实现进展和待办事项，应同步记录到 `context/` 目录。
- 进展记录保持简洁，只写关键信息；详细过程或长输出不写入主进展文件。
- `context/project_progress.md` 是项目进展主记录。
- `context/architecture.md` 记录仓库结构和关键文件职责。

文件说明：
- `architecture.md`：当前仓库结构、日志数据布局、脚本职责。
- `project_progress.md`：日志审查系统的目标、已知数据范围、分析方向、进展记录和待办。
- `核心功能设计.md`：基于样例日志讨论核心功能边界和解析规则。
