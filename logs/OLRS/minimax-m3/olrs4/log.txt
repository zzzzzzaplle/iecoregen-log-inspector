# Requirement
```text
Online Library System (OLS) provides easy access to customers to order different library items. A customer can place multiple orders. The status of an order can be pending or completed. Furthermore, each order is composed of multiple item lines. Each item line has a quantity. An item line is associated with a library item. The library item can be a book item or a digital item. Each library item has a status. The status can be available, hold, or loan. The book item can be of types - eBook format or print format. On the other side, the digital item can be an audio item or a video item. In addition, a digital item also has two options - downloadable and disc.
Functional requirement:
1. Add a new item line to order. Preconditions. The order must be in Pending status; the library item must be available (not Hold or Loan). Return true if item line added, false if validation fails.
2. Remove an item line from an existing order in Pending status. If successful: Return the updated count of item lines in the order. Reset the library item's status to available only if it was previously Hold (for print/disc items). Otherwise, retain its original status. If failed (order is completed): Return -1.
3. Handle an existing order. First, update Order Status to "completed". And then modify the library item's status from hold to loan only if the library item belongs to a print format book item or disc digital item.
4. Calculate the total downloads for a specific Audio digital item. Only consider orders with Completed status. Only count if the digital item's option is Downloadable (not Disc). Return total download count. If no download, return 0.
5. Count the total number of print-format book items in a given order only if the order status is completed. Return 0 if none.
```

Order::removeItemLine
Summary: Removes an item line from this order if the order is in pending status, resetting the associated library item's status to available when appropriate, and returns the updated number of item lines.
Algorithm:
  1. If this.status == COMPLETED, return -1
  2. Let libraryItem = itemLine.libraryItem
  3. Remove itemLine from this.itemLines
  4. If libraryItem.status == HOLD:
       4.1. If (libraryItem is BookItem AND libraryItem.type == PRINT_FORMAT) OR
               (libraryItem is DigitalItem AND libraryItem.option == DISC):
           4.1.1. Set libraryItem.status = AVAILABLE
  5. Return this.itemLines.size()

Pre-condition: The order's status must be PENDING; the supplied itemLine is expected to be a member of this.itemLines.
Post-condition: On success (returned value >= 0), itemLine is removed from this.itemLines; if the removed item's library item was previously HOLD for a print-format book or disc digital item, its status is reset to AVAILABLE, otherwise its status is retained. Related Features: status (OrderStatus), itemLines (List<ItemLine>)
